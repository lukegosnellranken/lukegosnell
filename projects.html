Horseman

Private project

A headless, lightweight, and non-proprietary content management and hosting solution I am currently working on. Horseman is built to give the customer a simple, reliable way to manage their blog content without worrying about the technical details. The front end runs on Next.js. Content lives in Strapi Cloud. The site is deployed through AWS Amplify.

Ungoogled Extensions

Code | Live Site

A simple site I built to help Chromium users easily download browser extensions. It currently handles 500+ requests per week from its many visitors.

Hidden Media Scraper

Code

A fully JavaScript project that is designed to scrape, validate, and archive hidden media files from the Epstein Library. It extracts URLs, verifies them, downloads and compresses the media into a ZIP archive, then lists the files that could not be validated. This project has many stars and several forks.

Master Tracker

Code | Contact for Live Demo

A tool for my house rules of the 1999 Pokemon board game Master Trainer. The site utilizes vanilla JavaScript to allow the player to easily store their captured Pokemon and keep track of their levels, attack power, and experience. I am currently experimenting with websockets in order for two players to be able to view each other's progress on separate devices.
